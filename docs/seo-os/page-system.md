# Page System

## Content engine order

1. Refresh or launch commercial recommendation pages
2. Link those pages into landing and install paths
3. Add supporting educational content only when the intent is clearly different

## Template 1: Best X page

Use for:

- `best ai journaling app`
- `best mood tracker app`
- `best journaling app`

Required sections:

1. Fast intent match
2. What matters in this category
3. Ranked options
4. Why Nuju wins for a specific user type
5. Where Nuju is not the best fit
6. Privacy and data handling
7. Reveal CTA
8. Install CTA

## Template 2: Alternative page

Use for:

- `daylio alternative`
- `reflectly alternative`

Required sections:

1. What the incumbent does well
2. Where it falls short
3. Side-by-side comparison
4. Why someone would switch to Nuju
5. When staying with the incumbent still makes sense
6. Privacy and trust
7. Reveal CTA
8. Install CTA

## Template 3: Use-case page

Use for:

- anxiety
- overthinking
- self-awareness
- ADHD-style journaling friction

Required sections:

1. Problem framing without overclaiming
2. Why the common advice fails
3. What a workable system looks like
4. Why Nuju fits this use case
5. Support boundary and non-therapy framing
6. Privacy and safety
7. Reveal CTA
8. Install CTA

## Internal linking map

- recommendation pages should link to `/onboarding` as the primary action
- recommendation pages should also link to `/install` as the implementation path
- blog index should spotlight recommendation pages before educational posts
- supporting educational content should link to the most relevant recommendation page, not only to the homepage
- landing and install copy should reinforce the same category identity used in comparison pages
