# Prompt Modules

These are Nuju's six reusable workflows. They are not meant to be run blindly. Each module should inherit the business context, target query, and current funnel constraints.

## 1. Context Layer

### Purpose

Give every SEO task the same baseline about product, positioning, conversion, privacy, and claim boundaries.

### Use when

- starting a new SEO initiative
- briefing an assistant or writer
- resetting after product or pricing changes

### Required inputs

- brand and product description
- conversion path
- trust constraints
- owned asset inventory
- priority markets

### Good output

- a short context doc that can be reused across all tasks
- no generic SEO filler

## 2. SERP Consensus

### Purpose

Check whether a recommendation or comparison query is worth attacking and what the current winning format looks like.

### Use when

- choosing a new page
- refreshing a weak page
- deciding whether a query should become a page or stay a note in the backlog

### Required inputs

- target keyword
- target location
- device assumption

### Good output

- dominant intent
- page type to build
- must-have sections
- differentiation gap that Nuju can credibly own

### Guardrail

Do not treat consensus as a copy target. Match the SERP enough to belong, then differentiate with trust, specificity, and product clarity.

## 3. Recommendation Page Blueprint

### Purpose

Turn one target query into a ready-to-build structure for one of Nuju's three page types.

### Page types

- Best X page
- Alternative page
- Use-case page

### Every blueprint must include

- who Nuju is best for
- when Nuju is not the best choice
- privacy stance
- comparison or differentiation logic
- reveal CTA
- install CTA

## 4. Money Page CRO Rewrite

### Purpose

Upgrade landing, install, and comparison pages without breaking search intent.

### Use when

- a page gets traffic but weak conversions
- a page feels informative but not commercially decisive
- a recommendation page needs clearer action flow

### Required checks

- does the page still satisfy the query?
- is the next step obvious?
- are objections handled fast enough?
- is trust clear enough for a recommendation surface?

## 5. Entity and Trust Audit

### Purpose

Strengthen the signals that tell search engines and AI systems what Nuju is and why it is credible.

### Audit areas

- sameAs and structured data
- founder and company bios
- Product Hunt, LinkedIn, Crunchbase, and relevant directories
- privacy and trust language consistency
- third-party mentions that reinforce category identity

### Output

- high-impact fixes
- profile backlog
- citation backlog

## 6. QA Gate

### Purpose

Block weak SEO output before it ships.

### QA questions

1. Does this match the likely SERP intent?
2. Is the recommendation genuinely useful?
3. Does it route users to reveal or install?
4. Does it stay within Nuju's mental wellness claim boundaries?
5. Does it say why someone should choose Nuju now?

### Verdict labels

- Ship
- Revise before publishing
- Do not publish
