# Nuju App Store Submission Pack

Use these files as the copy-and-paste source for App Store Connect.

- `review-notes.md` - reviewer instructions, demo flow, and safety notes.
- `privacy-label-draft.md` - conservative App Privacy questionnaire mapping.
- `metadata-draft.md` - app name, subtitle, description, keywords, and URLs.
- `screenshots-shot-list.md` - screenshot plan and exact story for the first submission.
- `submission-checklist.md` - final pass checklist before pressing Submit for Review.

Current recommendation: submit as a wellness journaling app, not a medical, therapy, or crisis-care app. Keep subscription language plain and make the 7-day trial visible only after the App Store Connect introductory offer is actually configured.
